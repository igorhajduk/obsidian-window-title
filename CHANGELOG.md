# Changelog

## 0.1.1

- Write settings once typing pauses instead of on every keystroke. Titles still update immediately, and pending edits are written when Settings closes or the plugin unloads.
- Lower the minimum Obsidian version to 1.13.0, the earliest release that provides the settings APIs the plugin uses.

## 0.1.0

- Add a shared vault title format with synchronized visual and text editors.
- Support vault, tab, file, path, and searchable frontmatter elements.
- Update titles independently for content windows and restore observed standard titles on disable.
- Preserve the last valid format while a template edit is incomplete.
- Show the full tile during dragging, fade its original position, and mark the insertion point before or after neighboring tiles.
